# PROJECT V — 시제품 완료 기준

**기준일:** 2026-11-19 · 이 목록을 모두 통과해야 main에 시제품으로 올린다. 기능 추가보다 "처음부터 끝까지 끊김 없이 동작"이 우선이다.

## 1. 한 판을 끝까지 할 수 있다
- [ ] 앱을 실행해 팀 두 개를 고르고 Bo3 시리즈를 시작할 수 있다.
- [ ] 밴픽을 사람이 한 단계씩 진행하고, AI가 상대 차례를 진행한다. 디사이더가 표시된다.
- [ ] 각 맵 경기를 경기 화면에서 진행한다: 전술 맵 모드와 팀 캠 모드를 전환할 수 있다.
- [ ] 타임아웃에서 지시를 내리고, 다음 라운드에 반영된다.
- [ ] 경기 후 리뷰에서 라운드별 판단 근거(계획, 상대 읽기, 계획 변경 사유)를 볼 수 있다.
- [ ] 시리즈 요약까지 도달한다. 중간에 오류·멈춤·빈 화면이 없다.
- [ ] 한국어와 영어 모두에서 위 흐름이 깨지지 않는다(넘침, 키 노출 없음).

## 2. 엔진이 믿을 만하다
- [ ] 160경기 검증에서 판정 지표 7/8 이상, 공격 승률 0.47–0.55.
- [ ] 설치 시점 인원이 많은 쪽이 더 이긴다(인원별 승률이 단조 증가).
- [ ] 스킬 off 기본 모드 결과가 스킬 작업 전후로 동일하다.
- [ ] 같은 시드 → 같은 경기·같은 시리즈.
- [ ] 반사실 테스트(단서, 기억, 계획, 숙련도, 스카우팅, 스킬)가 모두 통과한다.

## 3. 맵
- [ ] 11개 맵 데이터가 이름으로 로드되고 검증 테스트를 통과한다.
- [ ] Ascent 외 맵은 아직 Ascent 지형으로 플레이된다는 사실이 화면과 문서에 표시된다.
- [ ] 맵 지오메트리 파일(.blend, .glb)이 git에 하나도 없다.

## 4. 품질
- [ ] 타입체크 통과, 루트·round-simulator·match-runner·데스크톱 테스트 전부 통과.
- [ ] 데스크톱 빌드와 e2e 테스트 통과.
- [ ] 160경기 처리 시간이 크게 늘지 않았다(현재 약 75초).
- [ ] README와 문서가 현재 동작을 설명한다. 알려진 한계가 숨겨져 있지 않다.

## 시제품 이후로 미룬 것

- 계획 변경 사유 문구의 번역 키(현재 엔진 영어).
- 스킬 on 모드의 실측 밸런스.
